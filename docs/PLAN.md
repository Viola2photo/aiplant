# AI 植物生態影音平台 — 完整規劃

> 主題：大自然植物的生態與成長
> 產量目標：短影音 1–3 支/天；長影片 1 支/3 天
> 目標：定時自動製作 → 定時上傳 YouTube / Facebook / Instagram / Threads → 穩定收入
> 文件日期：2026-11-02（平台政策常變，動工前請再核對各平台最新規則）

---

## 0. 先說結論（坦白版）

1. **真正能賺到錢的只有 YouTube**。FB 次之（需要獨立經營、門檻不穩定）。IG 與 Threads 對「直接收入」幾乎沒有幫助，只適合當導流／品牌曝光。
2. **「全 AI、大量、重複模板、無真人加工」是目前平台打擊最重的類型**（YouTube 的「inauthentic / 重複性內容」政策、Meta 的「非原創內容」降觸及）。本規劃因此刻意設計成：**AI 負責產能，人工每天 15–30 分鐘做把關與差異化**。完全無人值守的版本，風險是被拒絕營利或整頻限流。
3. **短影音收入極低**（Shorts 每千次觀看約 US$0.01–0.07 等級）；**長影片才是主要收入**（自然／教育類 RPM 通常 US$1–5，英文受眾更高）。所以「每三天一支長片」比「每天三支短片」更重要，短片的任務是**導流與漲粉**。
4. **不要期待短期穩定收入**。合理預期：3–6 個月才可能達到 YouTube 營利門檻，9–12 個月才可能有「看得到的月收入」，要「穩定」通常需要多元收入（見第 7 節）。

### 各平台對收入的價值評級

| 平台 | 直接收入 | 角色 | 建議 |
|---|---|---|---|
| **YouTube**（長片＋Shorts） | ★★★★ 廣告分潤、會員 | 主要收入來源 | **第一優先，全力經營** |
| **Facebook**（Page＋Reels） | ★★☆ 內容營利計畫，條件與邀請制不穩定 | 次要收入＋觸及（華語區中高齡受眾多，植物／自然內容適合） | 第二優先，自動轉發即可 |
| **Instagram** | ★☆ 直接收入近乎沒有（Reels 獎金已大幅縮減，訂閱需 1 萬粉） | 品牌＋導流（簡介連結放聯盟行銷／商店） | 低成本同步發，**不投入額外製作** |
| **Threads** | ☆ 無影音營利機制，且以文字互動為主 | 導流、社群互動 | ⚠️ **對收入基本無效**。只做自動發「短片連結＋一句冷知識」，每天花費 0 分鐘；若無成效直接放棄 |

## 1. 帳號建立與設定（尚未申請 → 從這裡開始）

### 1.1 命名與品牌（第 0 天，先決定再申請）
- 一個**全平台一致**的品牌名與 handle（例：`@xxxPlantLife`），查好四個平台都沒被占用再註冊。
- 決定主語言：**建議主頻道繁體中文**；第 3 個月起視成效加開**英文頻道（獨立頻道，RPM 較高）**，不要混語言在同一頻道。
- 準備頭像、橫幅、簡介（含聯絡 Email），用同一套視覺。

### 1.2 建立順序與要點

| 順序 | 平台 | 做法 | 注意 |
|---|---|---|---|
| 1 | **Google 帳號 → YouTube 品牌頻道** | 新建專用 Google 帳號（不要混用個人）→ 建立「品牌帳號」頻道，可多人管理 | 開 2FA；手機驗證解鎖「進階功能」（上傳 >15 分鐘、自訂縮圖）；啟用**語言＝繁中、國家＝台灣** |
| 2 | **Facebook 粉絲專頁** | 需要一個真實的個人 FB 帳號當管理員 → 建立 Page → 用 Meta Business Suite 管理 | 用真實身分；不要用假帳號或多帳號規避，容易被連坐停權 |
| 3 | **Instagram 專業帳號** | 註冊後切換「創作者」帳號 → 連結到 FB Page | API 自動發文**必須**是專業帳號並與 Page 連結 |
| 4 | **Threads** | 用 IG 帳號直接開通 | 與 IG 同 handle |
| 5 | **Google AdSense**（達標後才申請） | YPP 通過後在 YouTube Studio 內申請 | 台灣需地址 PIN 信件驗證、稅務資料（W-8BEN）；美國觀眾收益可能被預扣稅，細節請問會計師 |

### 1.3 帳號「養號」與新帳號行為準則
- 前 7 天**不要**狂發：手動上傳 3–5 支、把簡介／頻道資訊填完整、訂閱同領域頻道。
- 之後再逐步提高到每日量（見第 6 節進度）。
- 一個人一組帳號；不要買帳號、不要互刷。

### 1.4 營利門檻（以建立時最新政策為準，動工前請查證）
- **YouTube YPP**：
  - 初階（粉絲贊助／會員等）：約 500 訂閱＋近 90 天 3 支公開上傳＋（3,000 小時長片觀看 或 300 萬 Shorts 觀看）
  - 廣告分潤：約 1,000 訂閱＋（4,000 小時公開長片觀看 或 1,000 萬 Shorts 觀看/90 天）
  - **Shorts 的觀看時數算不進長片的 4,000 小時** → 長片是營利關鍵
- **Facebook**：內容營利計畫採邀請／資格審核制，需持續達到追蹤數與觀看分鐘門檻，規則變動頻繁。
- 重點：**「重複性／大量製作內容」不會被營利**，要在每支影片有獨特腳本、旁白、剪輯與資訊價值。

## 2. 內容策略

### 2.1 五大內容支柱（建立辨識度＋方便系列化）

1. **生長縮時**：種子萌發、花開、藤蔓攀爬、菌類生長（視覺衝擊強，Shorts 友善）
2. **奇特植物生態**：食蟲植物、絞殺榕、寄生植物、擬態植物、會動的植物
3. **森林共生與生態網**：菌根網路、授粉、傳播種子、植物之間的化學溝通
4. **台灣在地植物與季節**：櫻花、桃花心木、台灣原生種、依月份推出（在地關鍵字競爭低）
5. **迷思與冷知識**：「仙人掌真的不用澆水嗎？」「竹子一天長 1 公尺？」（高互動、易引發留言）

### 2.2 影片規格

| 類型 | 長度 | 頻率 | 目的 |
|---|---|---|---|
| **短影音**（9:16） | 25–45 秒 | 起步每日 1 支，穩定後 2–3 支 | 漲粉、導流到長片 |
| **長影片**（16:9） | 8–12 分鐘（以滿足「中插廣告」） | 每 3 天 1 支（每月約 10 支） | **主要收入** |
| 加碼（第 4 個月起） | 1–3 小時「放鬆／助眠」植物縮時＋環境音合輯，由長片素材組合 | 每月 1–2 支 | 拉高觀看時數，低製作成本 |

> 短片 : 長片 = 約 6 : 1 到 9 : 1。建議**短片由長片腳本拆解產生**（一支長片 → 3 支短片），大幅降低主題研究成本，也讓導流自然。

### 2.3 每週內容節奏範例（單日 2 短＋長片每 3 天）

| 日 | 短片 1 | 短片 2 | 長片 |
|---|---|---|---|
| 一 | 生長縮時 | 冷知識 | ✔ 深度專題 A |
| 二 | 奇特植物 | 迷思破解 | — |
| 三 | 台灣在地植物 | 長片 A 切片 | — |
| 四 | 生長縮時 | 冷知識 | ✔ 深度專題 B |
| 五 | 森林共生 | 長片 B 切片 | — |
| 六 | 奇特植物 | 台灣在地植物 | — |
| 日 | 迷思破解 | 週回顧精華 | ✔ 深度專題 C |

### 2.4 品質與合規（非常重要）
- **事實查核**：AI 容易編造植物學資訊／混淆物種。流程中加「來源引用＋二次查核」步驟，腳本須附參考文獻（維基、植物學期刊、農業部／林業署資料）；描述欄放來源，同時提升可信度。
- **揭露 AI**：YouTube 對「擬真的合成內容」要求勾選揭露；Meta 也有 AI 標示。一律誠實標示，避免因被檢舉而受罰。
- **素材授權**：只用自己生成、CC0／商用授權素材（Pexels、Pixabay、NASA、Wikimedia 需確認授權）；音樂用 YouTube 音訊庫或有商用授權的來源。
- **避免全頻道同質**：每支影片至少有獨特腳本＋獨特主題＋不同開場；縮短「模板感」。
- **人工把關**：每天 15–30 分鐘審核佇列（腳本事實、畫面異常、字幕錯字），再進入排程。

## 3. 系統架構（自動化生產 → 自動發佈）

```
內容日曆 ─▶ 選題 ─▶ 腳本 ─▶ 事實查核 ─▶ 配音 ─▶ 畫面生成 ─▶ 字幕 ─▶ 剪輯合成
 (DB)      (LLM)    (LLM)    (LLM+來源)   (TTS)   (影片模型/素材)  (ASR)   (ffmpeg)
                                                                              │
         ┌──────────── 成效回饋（選題權重）◀── 分析 ◀── 發佈 ◀── 排程 ◀── 人工審核 ◀┘
```

### 3.1 模組

| 模組 | 說明 | 候選技術 |
|---|---|---|
| 內容日曆／資料庫 | 主題庫、狀態機（idea→script→rendered→approved→scheduled→published） | SQLite 起步，之後 Postgres／Cloudflare D1 |
| 選題 | 依支柱、季節、關鍵字、過往成效決定下一批主題；去重 | Claude API |
| 腳本 | 短片（Hook→重點→行動呼籲）、長片（章節化）；繁中、可轉英文 | Claude API |
| 事實查核 | 逐句列出主張＋來源，標記信心低的句子交人工 | Claude API＋網路檢索 |
| 配音 | 自然的中文旁白，固定一個聲線形成品牌 | ElevenLabs / Azure TTS / Google TTS |
| 畫面 | AI 影片生成（Veo / Kling / Runway 等）＋圖生影片＋授權素材＋Ken Burns 動態圖，**混用以控成本** | 各家 API（成本差異大，先小量試） |
| 字幕 | 自動轉錄並燒入字幕（短片必備） | Whisper |
| 合成 | 版型模板、片頭尾、BGM、字幕、縮圖 | ffmpeg / MoviePy |
| 審核 | 簡單網頁／Telegram 機器人：預覽→通過／退回 | 小型 web UI |
| 排程發佈 | 依平台最佳時段排程，失敗重試、記錄 | Python worker＋cron / 任務佇列 |
| 分析 | 拉回各平台數據，更新選題權重 | YouTube Analytics API、Meta Insights |

### 3.2 排程與運行環境
- 需要**常駐的小型主機**（VPS 或家用小主機）跑 worker；渲染影片吃 CPU，生成工作盡量走雲端 API。
- 影片檔放物件儲存（如 Cloudflare R2 / S3），資料庫記狀態。
- 批次作法：**每週日一次批量生成下週內容**（含審核），平日只負責排程發佈與例外處理。這比「每天即時生成」穩定得多。

### 3.3 各平台發佈的實務限制（影響設計）

| 平台 | 方式 | 重要限制 |
|---|---|---|
| **YouTube** | YouTube Data API `videos.insert` | ⚠️ **未通過 API 稽核的專案，上傳的影片會被強制設為「私人」**。必須提交 API Compliance Audit，或初期改用 YouTube Studio 原生排程／已稽核的第三方排程工具。上傳配額：預設每日 10,000 單位、每次上傳約 1,600 單位 → 約每日 6 支，足夠 |
| **Facebook Page** | Graph API 影片／Reels 發佈，支援 `scheduled_publish_time` | 需 Meta App＋權限審核（`pages_manage_posts` 等） |
| **Instagram** | Instagram Content Publishing API（Reels） | 需專業帳號＋連結 Page＋審核；每 24 小時有發佈上限 |
| **Threads** | Threads API（文字／連結／媒體） | 可做，但價值低 |

> 若不想處理 Meta／YouTube 的 API 審核（耗時 1–4 週不等），**階段一可先用第三方排程工具（Buffer / Metricool / Publer 等）或各平台原生排程**，自家系統先只做「生產＋產出檔案＋文案」，等帳號有成績再自建發佈器。這是風險最低的作法。

### 3.4 預估成本（概略，請以實際報價為準）
- LLM（腳本／查核）：低（每月數十美元內）
- TTS：低～中
- **AI 影片生成：最大變數**。若每支短片完全用影片模型生成 10–15 秒鏡頭，月成本可能達數百美元以上。省錢作法：圖生影片＋授權素材＋動態圖混合；長片以「旁白＋圖片動態＋少量生成鏡頭」為主。
- 主機／儲存：低
- **起步月預算建議抓 US$100–300**，試跑兩週算出實際單支成本再調整。

## 5. 風險清單

| 風險 | 影響 | 對策 |
|---|---|---|
| 被判定「重複性／大量生產內容」不給營利 | 高 | 人工審核、腳本差異化、控制量（先 1 支/天）、加入真人元素（例如自己錄的旁白或實拍縮時） |
| AI 事實錯誤 | 中高（損失信譽） | 查核流程、引用來源、置頂勘誤 |
| API 審核卡關 | 中 | 先用原生／第三方排程 |
| 帳號被停權 | 高 | 真實身分、不灌水、遵守素材授權、備份素材 |
| 影片模型成本失控 | 中 | 單支成本預算上限＋監控 |
| 平台政策改變 | 中 | 多平台＋第 7 節多元收入 |

## 6. 進度規劃（里程碑）

### 階段 0 — 準備（第 1 週）
- [ ] 決定品牌名、handle，查四平台可用性
- [ ] 建立 Google 帳號 → YouTube 品牌頻道；FB 個人帳號 → Page；IG 專業帳號；Threads
- [ ] 全部開 2FA；做頭像／橫幅／簡介
- [ ] 建立 Meta Business Suite；申請 Meta 開發者帳號與 App（先建立，審核晚點）
- [ ] 建立 Google Cloud 專案（YouTube API）
- [ ] 準備 5 個支柱各 10 個主題（共 50 個主題庫）

### 階段 1 — 手動試產（第 2–3 週）
- [ ] 用工具手動做出 10 支短片＋2 支長片，估算單支時間與成本
- [ ] 確定視覺風格、旁白聲線、片頭尾、字幕樣式
- [ ] 手動或原生排程發佈（每天 1 支短片），開始累積數據
- [ ] 目標：看哪類主題完播率最高

### 階段 2 — 自動化生產線（第 4–8 週）
- [ ] 寫腳本／查核／配音／合成流程，輸出可上傳的成品＋標題＋描述＋標籤＋縮圖
- [ ] 做審核佇列介面
- [ ] 週批次生成：每週日產下週內容
- [ ] 量提升到：短片 2 支/天、長片每 3 天 1 支
- [ ] 同步申請 YouTube API 稽核與 Meta 權限審核

### 階段 3 — 自動發佈與回饋（第 9–12 週）
- [ ] 上線自動排程發佈（YouTube / FB / IG / Threads）與失敗重試
- [ ] 分析數據回灌選題
- [ ] 視成效決定是否升到 3 支/天；表現差的支柱砍掉
- [ ] 評估 Threads、IG 是否繼續（成效不佳就停）

### 階段 4 — 營利與擴張（第 4–6 個月）
- [ ] 達標後申請 YPP 與 AdSense
- [ ] 開英文頻道（沿用腳本翻譯＋英文配音）
- [ ] 開始放聯盟行銷連結（第 7 節）

### 階段 5 — 收入多元化（第 7–12 個月）
- [ ] 會員制／超級感謝、數位商品、素材販售等
- [ ] 以數據淘汰低效內容，穩定製作成本

## 7. 讓收入「穩定」的多元來源

1. **YouTube 廣告分潤**（主要，需 YPP）— 長片為主
2. **聯盟行銷**（最快有收入的方式，不用等門檻）
   - 植物與園藝用品、種子、培養土、盆器、LED 植物燈、園藝書籍、縮時攝影器材
   - 台灣可用：蝦皮分潤、博客來聯盟、PChome／momo 聯盟；英文頻道可用 Amazon Associates
   - 放在影片描述／置頂留言／IG 簡介連結，並**誠實標示**
3. **品牌合作**：園藝、盆栽、保養品（植物萃取）、教育類，粉絲 1 萬後可開始接洽
4. **數位商品**：植物桌布、縮時影片素材包、植物圖鑑 PDF（Gumroad／Payhip）
5. **YouTube 會員／超級感謝**（達標後）
6. **授權素材販售**：實拍或高品質縮時素材（注意各素材站對 AI 內容的政策）

> 現實提醒：1 萬訂閱的小頻道，月廣告收入可能只有數十到數百美元。**聯盟行銷＋商品**往往是 1 年內更主要的「穩定」來源。

## 8. KPI 與決策規則

| 指標 | 目標 | 不達標時動作 |
|---|---|---|
| 短片平均完播率 | >60% | 改開頭 3 秒 Hook、縮短片長 |
| 長片平均觀看時長比例 | >40% | 重寫章節結構、縮短 |
